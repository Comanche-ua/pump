# PULSE — радар пампов Binance → USDT

Веб-приложение и Telegram-бот: следит **только за спот-парами к USDT** и присылает сигнал, когда на 15м / 30м / 1ч появляется подтверждаемый импульс. Между альтом и BTC/ETH не торгует и не сигналит.

Это **алерты, не автоторговля**. Ордера на биржу не отправляются.

## Что считает пампом

Скан не смотрит на «просто +%». Кандидат проходит жёсткие отсечки, затем скоринг 0–100:

| Фактор | Вес | Зачем |
| --- | --- | --- |
| Всплеск объёма к SMA20 | 22 | Без объёма — не импульс |
| Пробой Donchian 20 | 16 | Выход из диапазона |
| Расширение ATR | 12 | Волатильность реально выросла |
| Качество свечи | 12 | Закрытие у хая, без длинной верхней тени |
| Агрессия тейкера | 10 | Market buy доминирует |
| EMA 9 > 21 | 8 | Тренд совпадает |
| Окно RSI 14 (54–72) | 8 | Рано, не FOMO |
| Сила vs BTC | 7 | Не «весь рынок поехал» |
| Ускорение ROC | 5 | Ход разгоняется |

Отсечки: красная свеча, объём < 1.35×, доджи, wick-фейк, стейблы, плечевые UP/DOWN, оборот < порога, уже +35% за 24ч.

Классы: **ПАМП** ≥ 74, **СМОТРЕТЬ** 60–73, **ПОЗДНО** — высокий скор, но RSI/24ч уже растянуты.

## Telegram Mini App

1. [@BotFather](https://t.me/BotFather) → `/newbot` → скопировать token.
2. `/newapp` или Menu Button → URL этого приложения.
3. В приложении вкладка **Бот**: вставить token, написать боту `/start`, нажать «Найти» chat ID, «Тестовый ping».
4. Оставьте вкладку открытой — скан идёт по интервалу и шлёт новые ПАМП.

Token хранится только в браузере.

## GitHub Actions (бот без открытой вкладки)

Secrets репозитория:

- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`

Workflow `.github/workflows/pulse.yml` каждые 10 минут гоняет `src/bot-cli.ts` и шлёт сильные сигналы.

Локально:

```bash
TELEGRAM_BOT_TOKEN=… TELEGRAM_CHAT_ID=… npx tsx src/bot-cli.ts
```
