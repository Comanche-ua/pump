# Pump scan — простой Telegram-бот

Один файл на Python (`pump_bot.py`). Без сервера, без базы данных, без сайта.
Каждые 10 минут GitHub сам запускает скрипт, он проверяет спот-пары к USDT
на Binance и шлёт сигнал в Telegram, если видит резкий рост цены и объёма.

## Настройка (один раз)

1. Создайте бота через [@BotFather](https://t.me/BotFather) командой `/newbot`,
   скопируйте токен.
2. Напишите своему боту `/start`, затем откройте в браузере
   `https://api.telegram.org/bot<ваш_токен>/getUpdates` и найдите `"chat":{"id":...}` —
   это ваш chat ID.
3. В репозитории на GitHub: **Settings → Secrets and variables → Actions →
   New repository secret**. Добавьте:
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
4. Вкладка **Actions** → workflow **Pump scan** → **Run workflow** (проверить
   вручную). Дальше он сам будет срабатывать каждые 10 минут.

## Настройки чувствительности (необязательно)

Через переменные окружения в `pump-scan.yml` (секция `env:`) можно задать:

- `MIN_VOLUME_RATIO` — во сколько раз объём должен превышать средний (по
  умолчанию 1.8)
- `MIN_PRICE_CHANGE_PCT` — минимальный рост цены за свечу, % (по умолчанию 3.0)
- `MIN_QUOTE_VOLUME_USDT` — минимальный суточный оборот монеты, чтобы не
  ловить неликвид (по умолчанию 1 000 000)
- `INTERVAL` — таймфрейм свечей: `15m`, `30m`, `1h` (по умолчанию `15m`)

## Важно

Это только оповещения. Скрипт не покупает и не продаёт — ордера на биржу не
отправляются.
